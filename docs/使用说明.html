公文一键排版

v0.4.0 · Windows x64 · 自动识别排版 · 本地离线处理

直接拖入 DOCX → 自动识别文种与段落角色 → 按需要编辑简单段落 → 导出排好版的新 DOCX。

安装

  1. 将安装包复制到 Windows 电脑，双击“公文一键排版_Setup_0.4.0_x64.exe”。
  2. 按安装向导完成安装。程序与运行组件一起安装，无需另外安装 .NET 或开发工具。
  3. 从桌面或开始菜单打开“公文一键排版”。安装后可以拔掉 U 盘。

建议使用仍受支持的64位 Windows 11；目标 Windows 10 版本需按交付清单实测。安装采用当前用户权限。32位 Windows、Windows 7/8 和 Mac 不适用此安装包。

WPS / Word 工具栏插件

关闭办公软件安装后，重新打开支持 COM 的 WPS 文字或 Word，点击“公文排版 → 排版当前文档”。先将当前文档保存为 DOCX 并按 Ctrl+S；插件不会自动保存宿主内容。工具已运行时会接收文档，未导出的修改仍有确认提示。仅有 JS 加载项或策略禁止 COM 的版本需要另外适配。详见本目录“插件安装与使用.md”。

第一次使用

  1. 先拖入随附“示例文件”目录中的虚构示例，正式公文留到验收以后。每次拖入一个 DOCX。
  2. 程序自动识别标题、主送、正文、标题层级、附件说明和落款，并依据明确的标题文种匹配通知、请示或报告模板。识别不确定时会显示提示；仍可手动修改角色或模板。
  3. 默认自动模式无需逐段打勾。普通文字稿可直接点击“导出排好版DOCX”；含表格、图片或特殊结构时会要求一次确认。需要详细核对时可切换手动模式。
  4. 选中可编辑的简单段落，点击编辑，修改纯文本后再导出。普通自动编号段落也可编辑，输出保留编号及原有列表缩进。修订、书签批注、超链接或嵌入对象段落仍在 WPS/Word 中编辑、保存后重新导入。
  5. 选择新文件名输出，原稿和已有输出不会覆盖。点击“打开输出文档”，使用 Windows 对 DOCX 的默认关联打开；也可在 WPS、Word 中分别打开输出。
  6. 检查实际页数、换行、页码、表格和落款。确认以后再打印；PDF 通过 WPS 或 Word 自己的导出功能生成。

输出在哪里，如何输出

  1. 导入文件后，在窗口底部的“4 导出”区域点击“导出排好版 DOCX”。
  2. 弹出保存窗口，选择桌面、单位文档目录或 U 盘中的目标文件夹，并填写一个新文件名，点击“保存”。没有固定输出目录，由这一步选择。
  3. 显示导出成功后，底部会显示完整输出路径；可以复制路径，点击“打开输出文档”或“输出目录”查看。
  4. 如果没有出现成功提示和输出路径，说明尚未导出；按屏幕提示处理缺字体、源文件更新或不支持的结构后再试。

编辑保护与自动编号

有权处理该文件时，保持勾选“仅在输出副本中解除编辑限制（原稿不变）”。工具解除新副本的编辑/写入限制，保留原稿。自动编号不再等同“受保护”：普通编号文字可以编辑，编号定义、序列和列表缩进保留。复杂字段、修订及对象继续保留。

若文件打开时要求密码、文件加密或使用企业权限管理，请在 WPS/Word 中凭有效权限打开并另存为可读 DOCX 后再导入。工具不会破解打开密码。

WPS 保持打开时使用

在 WPS 中编辑时可以保持文档打开。请先按 Ctrl+S 保存修改，再把已保存的 DOCX 拖到本工具；程序读取磁盘保存的版本，不会读取尚未保存的 WPS 内容。可以选择置顶，让工具伴随办公窗口使用。

如果导入后又在 WPS 中保存了新修改，导出时会提示重新导入，避免按过期识别结果排版。工具内有尚未导出的编辑时，换文件或关闭会提示处理这些编辑。输出新文件后可继续在 WPS 或 Word 中编辑。

字体缺失

模板的默认标题字体是“方正小标宋简体”，正文“仿宋”、一级“黑体”、二级“楷体”，西文“Times New Roman”。程序只检查实际用到的字体，不会安装或替换字体。

提示缺字体时，选择本机已安装且符合单位要求的字体，或由单位提供有授权的字体安装。选择其他字体会改变排版效果，须由模板负责人确认。安装包不附带商业字体。

支持范围与人工检查

情况处理方式
普通单节 DOCX 文字稿识别段落，按确认的规则修改格式，另存新文件。
表格、图片、特殊对象保护原有对象，显示复核提示，须确认后继续；内部对象不会被当作普通正文统一重排。
可读 DOCX 的编辑或写入保护勾选“仅在输出副本中解除编辑限制”，可编辑简单段落并导出可编辑的新副本，原稿不变。该选项不处理打开文件所需的加密密码。
修订、多节复杂版式修订内容保留；不支持的复杂版式停止自动处理。请在办公软件中整理副本后重新导入。
DOC、DOCM、WPS专用格式、扫描PDF首版不直接处理；DOC/WPS可在已有办公软件中另存为DOCX。不要只改扩展名。
正式红头、版记、盖章和涉密环境需要额外单位模板与流程验收，不能仅凭本工具输出推定已通过。

原稿、安全与记录

全程在本机处理，不上传正文，不执行宏或主动访问文档外链。只有明确编辑的简单段落会在输出中修改文本，其他内容保留；只另存新文件。源文件在导入后发生变化，会阻止使用旧识别结果。模板配置和审计元数据保存在当前用户的本地应用数据目录；审计不保存正文、源文件名和文件路径。

卸载只删除安装组件，原稿、输出、公文模板配置和审计记录保留。建议把原稿和输出放在单位批准的文档目录，并按单位制度备份。

WPS 与 Word 验收

  1. 在 WPS 中处理示例，再在 Word 中打开并另存。
  2. 在 Word 中打开示例并另存，再用工具处理，然后回到 WPS 检查。
  3. 比较正文与数字、标题层级、字体、缩进、编号、表格、分页、页码和落款。实际打印预览也要确认。
  4. 记录 Windows、WPS、Word 和字体版本。未实际测试的版本不视为已支持。
