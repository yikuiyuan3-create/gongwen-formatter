# Windows / WPS / Word 实机验收清单

填写 Windows 版本与位数、WPS产品与版本、Word产品与版本、所用字体。不要填写患者或业务敏感资料。先使用随附虚构样例。

- [ ] 普通用户安装成功；仅本插件的HKCU注册项变化，桌面与开始菜单可启动。
- [ ] .NET Framework 4.8不足时明确停止；办公软件开启时阻止安装/更新/卸载。
- [ ] 32/64位Word及支持COM的WPS分别记录版本并验证出现“公文排版”选项卡。
- [ ] 点击工具栏导入已保存DOCX；有未保存修改/新建/旧DOC时明确提示，不调用宿主Save/SaveAs。
- [ ] 排版工具已运行时收到当前文档，最小化窗口恢复；忙碌或模态对话框中提示稍后重试。
- [ ] 导出中再次点击工具栏不丢失当前修改；取消换稿保留原编辑。
- [ ] 只安装WPS的机器也可导入、配置、排版、另存。
- [ ] WPS保持文档打开，Ctrl+S后将同一个DOCX拖入工具，普通文字稿无需逐段打勾即可导出。
- [ ] 通知、请示、报告根据明确标题自动选择模板；原稿已有标题样式/大纲层级被识别。
- [ ] 编辑简单段落后导出，只有明确修改的内容变化，原稿不变。
- [ ] 普通直接/样式继承自动编号段落可编辑，输出的编号序列、原编号缩进及定义保留；修订、书签、超链接或对象段落保留特殊结构。
- [ ] 未导出的段落编辑在换文件/关闭前有提示；不误丢编辑。
- [ ] 导入后在WPS保存新改动，导出明确提示重新导入；不静默使用旧分析。
- [ ] 置顶可以开关；忙碌时不能再导入或编辑。
- [ ] 不会重复打开第二个程序；程序运行中不能安装更新或卸载。
- [ ] 缺字体明确提示；由操作者选择已安装字体后才继续。
- [ ] 确认标题、四层标题、主送、正文、附件说明、单位署名和日期的角色。
- [ ] “4 导出”的主要按钮文字在正常、忙碌状态均可读；小屏幕和系统缩放时能看到导出区域。
- [ ] 点击导出选择目标文件夹，成功后显示完整可复制路径；打开输出文档与输出目录指向真实结果。
- [ ] 先使用07保护编号虚构样例：编辑正文、保持副本策略勾选、导出后WPS与Word均可编辑，编号无变化。
- [ ] 成功导出新的DOCX，原稿SHA-256不变，已有输出不覆盖。
- [ ] WPS输入→工具→WPS；Word输入→工具→WPS。
- [ ] WPS输入→工具→Word；Word输入→工具→Word。
- [ ] 输出由WPS另存后Word打开；由Word另存后WPS打开。
- [ ] 双端无修复提示、乱码、内容遗漏、编号异常或对象丢失。
- [ ] 检查每页标题断行、表格跨页、页码、单位署名与日期，实际打印预览符合确认模板。
- [ ] 对已排版文件再运行，不添加重复空行或重复内容。
- [ ] 编辑保护DOCX生成可编辑副本，原稿哈希不变；不勾选解除副本限制时明确提示。多节、带修订、损坏或加密文档保留边界或明确提示。
- [ ] 成功任务留审计元数据，记录不含正文、文件名或路径。
- [ ] 卸载后原稿、输出、配置及审计仍在，未知安装目录文件不删除。

验收结论只能填写“通过”“失败”或“未执行”，每个结论附实际证据。生成安装包不等于已完成此清单。
