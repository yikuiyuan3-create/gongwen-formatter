# WPS / Word 工具栏插件安装与使用

版本：0.4.0 测试版。发布日期：2026-10-24。源码 MIT 免费开源。

## 安装

从 GitHub Release 下载 x64 安装包，并对照 SHA256SUMS.txt 核验。关闭 WPS、Word 和公文排版工具后安装。安装器只为当前 Windows 用户注册自己的 COM 加载项，无需管理员权限，不改变其他插件或 Office 安全设置。

插件需要 .NET Framework 4.8 或更新4.x。缺少时安装器会停止，可从[微软官方 .NET Framework 4.8 下载页](https://dotnet.microsoft.com/download/dotnet-framework/net48)安装或请单位 IT 配置。

安装后重新启动 WPS 文字或 Windows 桌面 Word，查找“公文排版”选项卡。32位和64位 Office 使用同一个 AnyCPU 加载项，仍需按具体宿主版本验收。

## 工具栏与输出

- **排版当前文档**：当前文档先保存为 DOCX 并按 Ctrl+S。插件只读取已保存版本，不会自动保存或覆盖宿主文件。
- **打开排版工具**：打开独立窗口，也可以拖入一个 DOCX；多个调用使用同一工具实例。
- **使用说明**：显示内置操作说明，无需网络。

在排版窗口核对模板、编辑文字，然后点击底部“4 导出 → 导出排好版 DOCX”。在保存窗口选择目标文件夹和新文件名。没有固定输出目录；成功后显示完整路径，“打开输出目录”可直接查看。

可读的编辑/写入限制可仅在新副本中解除，原稿不变。带打开密码、企业权限管理或无法读取的文件，须先在办公软件中凭有效权限打开并另存。普通编号可编辑文字，编号、缩进和制表位保留；复杂字段、修订与对象仍受保护。

## 没看到工具栏

1. 确认安装后已退出并重新启动办公软件，排版窗口标题显示 v0.4.0。
2. Word：文件 → 选项 → 加载项 → 管理“COM加载项” → 转到，检查“公文一键排版”。WPS 在提供该功能的版本中可从“开发工具 → COM加载项”检查。
3. 单位策略禁止加载、只有 JS 加载项或宿主不提供所需接口时，不要修改安全策略。将具体版本/位数和脱敏现象交给 IT 或本项目维护者；桌面拖入工具仍可使用，但不代表工具栏已验收。

## 更新与卸载

更新或卸载前关闭 WPS、Word 和排版窗口。卸载只移除本插件注册项和已知安装文件，保留原稿、排版结果、用户模板、审计与未知文件。安装包尚未商业代码签名，单位策略阻止时交由 IT 核验来源和哈希。
