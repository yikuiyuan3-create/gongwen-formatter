# 格式规则来源与适用范围

基础格式参考记录日期：2026-10-01。以下为现有基础模板的规则出处，不代表软件已经通过完整正式公文验收。

- [GB/T 9704—2012 官方版本与现行状态](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F3CC9BEF482524C895FDA7A08BB4A70E)
- [官方单位公开的标准正文](https://jcy.xjbt.gov.cn/c/2019-01-31/7176573.shtml)
- [微软 .NET 发布与支持政策](https://dotnet.microsoft.com/en-us/platform/support/policy)

基础文字稿模板采用A4、正文三号、标题二号、上白边和左白边及版心相关规则；正文首行采用两字缩进，层级标题区分字体。默认每页22行、每行28字。以用户确认的单位模板和实际办公软件打印结果作为最终验收依据。

其余页边距依据A4和版心尺寸换算，程序设置与字体、网格、排版引擎共同决定实际版式。模板参数可调整，但自定义设置不能自动宣称国标合格。当前程序没有实现完整正式公文所有要素与印制要求，也不能检测纸张、油墨或装订是否达标。

通知、请示、报告模板共享基础文字稿版式，文种与正文内容均由用户确认。公文语义与法规审核不由本软件替代。
